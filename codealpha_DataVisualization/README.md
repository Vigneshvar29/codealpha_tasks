# Task 2 - Data Visualization

Visualizes the books dataset from Task 1 using Matplotlib and Seaborn.
Generates a 4-chart dashboard saved as a PNG image.

## Charts included

- Bar chart — Rating distribution
- Histogram — Price distribution with mean line
- Horizontal bar — Top 10 most expensive books
- Pie chart — Stock availability

## How to run

```bash
pip install -r requirements.txt
python visualize.py
```

## Note
Place `books_dataset.csv` (from Task 1) in the same folder before running.
If not found, the script runs on sample data automatically.

## Output
`books_dashboard.png` — saved in the same folder.
